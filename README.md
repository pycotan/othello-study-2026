# オセロ定石学習アプリ (Othello Study 2026)

オセロの主要な定石（13種類）を実際に盤面を操作しながら学習できるWebアプリケーションです。

## 🚀 デモ
以下のリンクから実際に動作を確認いただけます。
https://pycotan.github.io/othello-study-2026/

## ✨ 主な機能
- **リアルタイム定石判定**: 打った手がどの定石に該当するかを瞬時に判定（野ウサギ、Fローズなど13種類に対応）。
- **オセロ基本ロジック**: 石の設置判定、および8方向へのひっくり返し処理の実装。
- **棋譜座標表示**: 初心者でも分かりやすい縦1-8、横a-hのラベル表示。

## 🛠 使用技術
- **HTML5 / CSS3**: レスポンシブなグリッドレイアウトによる盤面実装。
- **JavaScript (Vanilla JS)**: 外部ライブラリを使用せず、純粋なロジックのみで定石判定エンジンを実装。
